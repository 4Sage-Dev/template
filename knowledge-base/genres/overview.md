# Game Genres Reference

Quick-reference for common game genres. Use this to ground genre recommendations in real player expectations, typical mechanics, and market norms.

---

## Platformer

| Attribute | Details |
|---|---|
| **Core expectations** | Precise movement, jumping between platforms, spatial challenges |
| **Typical mechanics** | Jump, double-jump, wall-jump, dash, collectibles, checkpoints, hazard avoidance |
| **Session length** | 10-30 min (level-based); longer for exploration platformers |
| **Audience** | All ages; skews younger for casual, older for precision/hardcore |
| **Monetization** | Premium purchase; DLC level packs; cosmetics in live-service titles |
| **Reference games** | Super Mario Bros. Wonder, Celeste, Hollow Knight |

---

## RPG (Role-Playing Game)

| Attribute | Details |
|---|---|
| **Core expectations** | Character growth, narrative choices, stat-driven progression, world exploration |
| **Typical mechanics** | Experience points, leveling, skill/stat allocation, equipment, quests, dialogue trees, turn-based or action combat |
| **Session length** | 30 min - 4+ hrs; total playtime 20-200+ hrs |
| **Audience** | Teens to adults; story-driven and systems-driven players |
| **Monetization** | Premium ($40-70); DLC/expansions; cosmetic MTX in online RPGs; gacha in mobile JRPGs |
| **Reference games** | Baldur's Gate 3, Final Fantasy VII Rebirth, Divinity: Original Sin 2 |

**Sub-genres to be aware of:** Action RPG (Diablo IV, Elden Ring), JRPG (Persona 5), CRPG (Pillars of Eternity), MMORPG (FFXIV, WoW).

---

## FPS / Shooter

| Attribute | Details |
|---|---|
| **Core expectations** | Precise aiming, fast reflexes, weapon variety, satisfying gunplay feel |
| **Typical mechanics** | Aiming/shooting, reloading, cover, health/shield, weapon switching, grenades, movement abilities |
| **Session length** | 15-45 min per match (multiplayer); 6-15 hrs campaign |
| **Audience** | Teens to young adults; predominantly male but broadening |
| **Monetization** | Premium ($60-70); battle passes; cosmetic MTX; free-to-play with skins |
| **Reference games** | DOOM Eternal (single-player), Counter-Strike 2 (competitive), Destiny 2 (looter-shooter) |

---

## Strategy - Real-Time (RTS)

| Attribute | Details |
|---|---|
| **Core expectations** | Base building, army management, real-time decision-making under pressure |
| **Typical mechanics** | Resource gathering, unit production, tech trees, fog of war, micro/macro management, map control |
| **Session length** | 20-60 min per match; campaigns 15-40+ hrs |
| **Audience** | Older teens to adults; high skill ceiling attracts competitive players |
| **Monetization** | Premium; expansion packs; commander/faction DLC |
| **Reference games** | StarCraft II, Age of Empires IV, Command & Conquer Remastered |

---

## Strategy - Turn-Based

| Attribute | Details |
|---|---|
| **Core expectations** | Thoughtful planning, tactical positioning, meaningful choices per turn |
| **Typical mechanics** | Grid or hex movement, action points, unit abilities, terrain effects, permadeath (optional), campaign layer |
| **Session length** | 30 min - 3+ hrs (one-more-turn syndrome); campaigns 30-100+ hrs |
| **Audience** | Adults; appeals to analytical/patient players |
| **Monetization** | Premium; DLC factions/campaigns; expansion packs |
| **Reference games** | XCOM 2, Civilization VI, Into the Breach |

---

## Puzzle

| Attribute | Details |
|---|---|
| **Core expectations** | Mental challenge, "aha" moments, clear rules with emergent complexity |
| **Typical mechanics** | Pattern matching, spatial reasoning, logic deduction, physics manipulation, sequencing |
| **Session length** | 2-30 min per puzzle; mobile sessions even shorter |
| **Audience** | Broadest demographic; strong casual and mobile appeal |
| **Monetization** | Premium (indie); free-to-play with ads/energy (mobile); hint/skip IAP |
| **Reference games** | Tetris, Portal 2, Baba Is You |

---

## Survival

| Attribute | Details |
|---|---|
| **Core expectations** | Resource scarcity, environmental threats, crafting, tension from vulnerability |
| **Typical mechanics** | Hunger/thirst/health meters, crafting, building shelter, exploration, day/night cycle, hostile enemies/environment |
| **Session length** | 1-4+ hrs; open-ended total playtime |
| **Audience** | Teens to adults; appeals to players who enjoy emergent stories and sandbox systems |
| **Monetization** | Premium (Early Access common); cosmetic DLC; dedicated server hosting |
| **Reference games** | Subnautica, Valheim, Don't Starve |

---

## Sandbox / Building

| Attribute | Details |
|---|---|
| **Core expectations** | Creative freedom, player-driven goals, expressive building tools |
| **Typical mechanics** | Block/object placement, terrain manipulation, resource gathering, sharing/multiplayer, optional survival elements |
| **Session length** | 30 min - many hours; no natural endpoint |
| **Audience** | All ages; very strong with younger players and creative types |
| **Monetization** | Premium; cosmetic/skin packs; user marketplace; subscription (Roblox model) |
| **Reference games** | Minecraft, Terraria, Roblox |

---

## Roguelike / Roguelite

| Attribute | Details |
|---|---|
| **Core expectations** | High replayability through randomization, permadeath (full or partial), mastery over many runs |
| **Typical mechanics** | Procedural level generation, permadeath, run-based progression, random item/power selection, meta-progression (roguelite) |
| **Session length** | 15-60 min per run; hundreds of hours total |
| **Audience** | Core gamers; players who enjoy mastery and variety |
| **Monetization** | Premium ($10-30); DLC content packs |
| **Reference games** | Hades II, Slay the Spire, Dead Cells |

**Key distinction:** Roguelike = full reset on death. Roguelite = some persistent upgrades carry between runs. Most modern hits are roguelites.

---

## Fighting

| Attribute | Details |
|---|---|
| **Core expectations** | 1v1 (or small team) combat mastery, frame-precise inputs, character matchup knowledge |
| **Typical mechanics** | Combo strings, special moves, blocking/parrying, meter management, frame data, hitboxes/hurtboxes |
| **Session length** | 5-15 min per match; training mode sessions vary widely |
| **Audience** | Teens to adults; strong competitive/esports community; high skill floor is a barrier |
| **Monetization** | Premium ($40-60); character DLC; season passes; cosmetics |
| **Reference games** | Street Fighter 6, Tekken 8, Super Smash Bros. Ultimate |

---

## Racing

| Attribute | Details |
|---|---|
| **Core expectations** | Speed, vehicle mastery, track knowledge, competitive placement |
| **Typical mechanics** | Acceleration/braking/steering, drifting, boost/nitro, vehicle tuning, track hazards, rubber-banding AI (arcade) or sim physics |
| **Session length** | 5-15 min per race; career modes 10-50+ hrs |
| **Audience** | All ages for arcade; adult sim enthusiasts for simulation |
| **Monetization** | Premium; car/track DLC; cosmetics; in-game currency (mobile often aggressive IAP) |
| **Reference games** | Mario Kart 8 Deluxe (arcade), Forza Motorsport (sim), Gran Turismo 7 (sim) |

---

## Simulation

| Attribute | Details |
|---|---|
| **Core expectations** | Realistic or thematic modeling of a system; mastery through understanding complex interconnected rules |
| **Typical mechanics** | System modeling, management dashboards, cause-and-effect chains, sandbox scenarios, time controls |
| **Session length** | 30 min - 4+ hrs; open-ended |
| **Audience** | Adults; niche but deeply dedicated audiences per sub-genre |
| **Monetization** | Premium; DLC packs (new content/systems); expansion packs |
| **Reference games** | Cities: Skylines II (city builder), Microsoft Flight Simulator (vehicle sim), Stardew Valley (life sim) |

**Sub-genres:** City builder, farming sim, life sim, vehicle sim, management sim (Two Point Hospital), tycoon.

---

## Visual Novel

| Attribute | Details |
|---|---|
| **Core expectations** | Story-first experience, branching narrative, character relationships, multiple endings |
| **Typical mechanics** | Dialogue choices, branching paths, affinity/relationship tracking, CG gallery, occasional minigames or puzzle segments |
| **Session length** | 30 min - 2 hrs per session; total 5-50+ hrs depending on routes |
| **Audience** | Teens to adults; strong in Japan; growing Western audience; overlaps with anime/manga fandom |
| **Monetization** | Premium ($10-40); route/episode DLC; voice pack DLC |
| **Reference games** | Steins;Gate, Doki Doki Literature Club, Ace Attorney series |

---

## Idle / Incremental

| Attribute | Details |
|---|---|
| **Core expectations** | Numbers go up; satisfying automation; progress even while away |
| **Typical mechanics** | Click/tap to earn currency, auto-generators, prestige/reset layers, upgrades, offline progress calculation |
| **Session length** | 1-10 min active check-ins; runs indefinitely in background |
| **Audience** | Broad casual audience; mobile-dominant; appeals to optimization-minded players |
| **Monetization** | Free-to-play with ads; time-skip IAP; premium currency; boost purchases |
| **Reference games** | Cookie Clicker, Adventure Capitalist, Melvor Idle |

---

## Battle Royale

| Attribute | Details |
|---|---|
| **Core expectations** | Large-scale last-player-standing competition, shrinking play area, looting under pressure |
| **Typical mechanics** | Drop/spawn on large map, loot weapons/gear, shrinking safe zone, elimination, squad or solo modes |
| **Session length** | 15-25 min per match |
| **Audience** | Teens to young adults; massive casual and competitive overlap |
| **Monetization** | Free-to-play dominant; battle passes; cosmetic skins; limited-time events |
| **Reference games** | Fortnite, Apex Legends, PUBG |

---

## Horror

| Attribute | Details |
|---|---|
| **Core expectations** | Fear, tension, atmosphere, vulnerability; the player should feel unsafe |
| **Typical mechanics** | Limited resources (ammo, light), jump scares, environmental storytelling, stealth/hide mechanics, sound design as gameplay |
| **Session length** | 30 min - 2 hrs (tension fatigue limits sessions); total 5-15 hrs |
| **Audience** | Teens to adults; streamers/content creators drive significant visibility |
| **Monetization** | Premium ($20-40); DLC chapters/stories |
| **Reference games** | Resident Evil Village, Amnesia: The Bunker, Phasmophobia |

**Note:** Horror is often combined with other genres (survival horror, horror puzzle, horror FPS). The genre label primarily describes tone and player emotional state.

---

## Metroidvania

| Attribute | Details |
|---|---|
| **Core expectations** | Interconnected world map, ability-gated exploration, backtracking with new powers, satisfying discovery |
| **Typical mechanics** | Ability unlocks that open new areas, non-linear exploration, map reveal, boss fights, hidden secrets, fast travel points |
| **Session length** | 30 min - 2 hrs; total 10-30 hrs |
| **Audience** | Core gamers; fans of exploration and mastery |
| **Monetization** | Premium ($15-40); DLC expansions (new areas/abilities) |
| **Reference games** | Hollow Knight, Metroid Dread, Ori and the Will of the Wisps |

---

## MOBA (Multiplayer Online Battle Arena)

| Attribute | Details |
|---|---|
| **Core expectations** | Team-based competitive play, hero/champion mastery, strategic map objectives, deep meta-game |
| **Typical mechanics** | Lane pushing, last-hitting minions, hero abilities (QWER), itemization, jungle objectives, team fights, roles (carry, support, tank) |
| **Session length** | 20-50 min per match |
| **Audience** | Teens to young adults; highly competitive; strong esports scene |
| **Monetization** | Free-to-play; champion/hero unlocks; cosmetic skins (primary revenue); battle passes |
| **Reference games** | League of Legends, Dota 2, Pokemon Unite (mobile-simplified) |

---

## Cross-Genre Notes

- Most modern games blend genres. Use these as building blocks, not rigid categories.
- When a user describes a game concept, identify the primary genre (drives core loop) and secondary genres (adds flavor/systems).
- Genre expectations set player mental models. Violating them needs justification; subverting them deliberately can be a strength.
- Monetization norms are genre-dependent. A battle pass feels natural in a Battle Royale but alien in a Visual Novel.
